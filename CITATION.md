# Citation and attribution

The scientific manuscript combining matched-window EHT fitting and carbon benchmarks is a research draft. **A published DOI, final article title and author roster are not yet established in this repository; please do not invent a journal citation.**

When presenting YAeHMOP-generated scientific results, cite the **upstream YAeHMOP/bind authors** G. A. Landrum and W. V. Glassey and consult the [upstream project and manual](https://github.com/greglandrum/yaehmop) for the recommended form. If you use this frontend for your own publication, cite this repository's specific Git commit hash and retrieval date, along with the original electronic-band reference dataset and its proper attribution.

If a citable archival software release or a reviewed paper becomes available, this file can be updated with its DOI and complete bibliographic entry.
