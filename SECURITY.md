# Security

Do not execute untrusted solver binaries or parameter files from unknown parties. The frontend invokes a separately installed local YAeHMOP `bind` process only on explicit physical-computation commands. No GitHub Action executes it.

The raster reader rejects truncated images, oversized pixel arrays, invalid color profiles, high-precision modes that would be silently quantized, animations and multipage images. Pillow should still be updated regularly because image decoders are third-party native code.

For a security-sensitive finding, avoid posting exploitable payloads or private files in public issues. Contact the repository maintainer privately through their verified GitHub profile before a public disclosure. This project is research software, not a hardened hosted service.
